# Student AI Bot — коммерческий MVP

Telegram-бот разбирает текстовые учебные задачи по разным предметам, объясняет решение
по шагам и помогает подготовиться к защите. Первый разбор бесплатный, дальше продаётся
один разбор или пакет из пяти разборов за Telegram Stars. Рабочий бот:
[@TaskMentorBot](https://t.me/TaskMentorBot).

## Почему именно этот продукт

Первая версия принимает задачи по разным предметам, но продаёт конкретный результат:
пошаговый разбор, проверку и подготовку понятного объяснения преподавателю. Приветствия
и вопросы о самом боте распознаются до списания попытки; типовые вопросы вынесены в
бесплатную команду `/faq`.

Первая гипотеза цены: **100 Stars за 5 разборов**. Это тест, а не доказанная цена.
Смотрите конверсию `/start → бесплатный ответ → /buy → оплата` и меняйте цену только
после первых 10–20 целевых пользователей.

## Что входит в MVP

- текстовое условие задачи по любому учебному предмету;
- одна общая бесплатная первая задача: её можно отправить текстом или фотографией;
- после использования бесплатной попытки полный фоторазбор одной фотографии требует
  подтверждения цены: 100 Stars или пять оплаченных разборов;
- память фоторазбора на 24 часа: распознанные условия хранятся в SQLite, поэтому задачи
  с одной фотографии можно решать по очереди без повторной оплаты фото; `/newtask`
  очищает сохранённый контекст;
- распознавание учебной задачи до списания попытки;
- бесплатная команда `/faq`;
- один бесплатный разбор на Telegram-аккаунт;
- покупка одного разбора или выгодного пакета через Telegram Stars;
- безопасное начисление кредитов без дублей платежа;
- возврат кредита при технической ошибке;
- персональные реферальные ссылки с наградой за первую покупку приглашённого;
- отдельные партнёрские ссылки со статистикой запусков, покупателей и выручки;
- однократный возвратный бонус неактивным пользователям без покупок;
- безлимитный доступ для заранее разрешённых пользователей;
- учёт токенов и расчётной себестоимости каждого AI-ответа;
- команды `/balance`, `/buy`, `/referral`, `/about`, `/terms` и `/paysupport`;
- компактная обратная связь после ответа и бесплатное уточнение «объяснение для защиты»
  в пределах сохранённого в памяти процесса контекста ответа;
- событийная аналитика запуска без текстов задач, фотографий и ответов AI;
- защищённые команды владельца `/funnel` и `/funnelcsv` со статистикой за 1, 7 или 30 дней.

Команда `/about` показывает текущую версию бота, основателя, фактическое число успешно
решённых задач и ссылку на публичный исходный код проекта.

Нет приёма PDF и других файлов, генерации изображений и офисных документов, подписки,
личного кабинета и панели администратора.
Владелец управляет партнёрскими ссылками командами `/partner` и `/refstats`.
Воронка доступна только `OWNER_TELEGRAM_ID`: `/funnel`, `/funnel 1`, `/funnel 7` или
`/funnel 30`. Она показывает уникальные старты, отправку задач, успешные ответы, открытие
покупки, запросы инвойсов, покупателей, платежи, Stars и отзывы. Таблица `events` хранит
только Telegram ID, имя события, короткий технический источник и время; содержимое задач
и ответов в аналитику не попадает.

Для визуального анализа используй `/funnelcsv 30`: бот пришлёт дневной CSV в UTC, включая
дни без активности и конверсии между этапами. В файле нет Telegram ID, имён или текстов задач;
его можно импортировать в Excel или Google Sheets.

## Минимальная архитектура

`Telegram → Python-бот (long polling) → OpenAI Responses API`

Тот же Python-процесс хранит пользователей, кредиты, платежи и расходы в SQLite.
Для первых десятков пользователей отдельный сервер базы и веб-приложение не нужны.

## Локальный запуск

Нужен Python 3.11 или новее.

1. Создайте бота через `@BotFather` и сохраните токен.
2. Создайте отдельный OpenAI API key и включите API billing. ChatGPT Plus этого не включает.
3. Скопируйте `.env.example` в `.env`, заполните секреты, контакт поддержки и свой
   Telegram ID в `OWNER_TELEGRAM_ID` для доступа к командам владельца.
4. В папке проекта выполните:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m app.bot
```

Пока процесс открыт, бот работает. Для первого теста это бесплатно и достаточно.
Позже его можно перенести на недорогой постоянно работающий сервер.

## Путь к первому платному заказу

1. Запустить бота локально и самому провести бесплатный и тестовый платёжный сценарии.
2. Лично написать 10 знакомым первокурсникам/старостам IT-групп; не спамить чаты.
3. Предложить бесплатный разбор реальной текущей лабораторной в обмен на честный отзыв.
4. После ответа спросить: «Это помогло бы защитить работу? Что было непонятно?»
5. Вторую задачу предложить через `/buy`. Первая успешная оплата — главный сигнал MVP.
6. Вручную записывать: приглашён, запустил, получил ответ, оплатил, вернулся.

Бесплатное привлечение: личные контакты, разрешённый пост в группе курса, демонстрация
одного обезличенного «до/после» и просьба старосте переслать ссылку. Массовый контент,
реклама и партнёрская программа до первой оплаты не нужны.

## Расходы и экономика

Обязательны только расходы OpenAI API; Telegram Bot API, BotFather, SQLite, Python и
локальный запуск бесплатны. При модели `gpt-5.6-luna` конфигурация считает стоимость по
ставкам из `.env`: $0.20 за миллион входных и $1.20 за миллион выходных токенов.
Например, 2 000 входных + 1 200 выходных токенов — около **$0.00184** до налогов и
курсовой конвертации. Фактические токены каждого ответа сохраняются в таблице `requests`.

Telegram требует Stars (`XTR`) для цифровых товаров и услуг внутри ботов. Выручка в
Stars не равна фиксированной сумме в тенге: цена покупки зависит от платформы и налогов,
а вывод идёт через механизм вознаграждений Telegram/Fragment. Поэтому цель 9 422 ₸
нужно отслеживать по фактически доступной к выводу сумме, а не по номиналу Stars.

## Перед публичным запуском

- включить двухэтапную защиту Telegram-аккаунта владельца;
- заполнить `SUPPORT_USERNAME`;
- проверить `/terms`, `/paysupport`, покупку и повторную доставку обновления;
- установить лимит расходов в OpenAI Platform;
- не публиковать `.env` и базу;
- уточнить налоговый статус и выдачу чеков у бухгалтера/официальных органов Казахстана.
